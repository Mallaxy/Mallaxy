## What I build

- 🤖 **Both sides of your AI product.** I build the AI your users touch, and the proof that it works. I owned an enterprise AI assistant's frontend, from the chat to replies rendered as financial charts and tables, and built the evals that hold a live, multi-turn conversation with it: a simulated user answers its questions and an LLM judge scores the result.
- 📏 **AI you can measure, at a cost you control.** I calibrated that LLM judge against QA's own review until it agreed 9 times in 10. Every run reports the tested assistant's own tokens, cost per model and latency.
- 🔁 **Big changes, zero downtime.** I moved a live AI assistant's frontend onto a new LLM backend with zero downtime and no rollbacks: both backends behind one feature flag, rolled out product by product.
- 🚀 **From idea to company standard.** I took the company's first standardized way to evaluate its AI assistants from proof of concept to a tool six AI assistant teams adopted in one quarter.
- 🧩 **Makes the whole team faster.** I built an internal VS Code extension (430+ downloads) so QA runs AI test suites without the command line, and a shared component library that cut duplicated UI code by nearly half.
